# Примеры: кружок понятности, «Понятные» в Anki, «Открыть в плеере» (0.6.1)

Статус: одобрено владельцем 2026-11-24 («Checkbox для всех видео из примеров. Да. Да. Да»; позже — «Да: открывать с
&t=»).

## Зачем

- Владелец (2026-11-24): ролики «Понятные» нельзя добавить в Anki — «это ошибка. Для этого они там, чтобы можно было на
  них опираться как на дополнительные исходные материалы».
- Дизайнер предлагает показывать процент понятности кружком на превью (макет владельца от 2026-11-24).
- Владелец: «вот открыть в плеере очень полезно чтобы открывалась в нашем плеере видео. Кнопку тоже в 0.6.1 взять».

**Причина ошибки с Anki.** `_buildUnderstandableCard` не создаёт чекбокс, а `getSelectedGatewayMedia` и
`clearSelection` смотрят только в `_youTubeCards`. Требования такого в спецификации 2026-11-21 нет: строка «these cards
do not need Anki selection checkboxes» появилась в плане.

## Что не делаем

- «Добавить в дополнительное видео» (владелец: «пока размышления», «не нужно»).
- Название ролика и длительность у карточек «С учётом моих знаний» (на макете есть, владелец просил про проценты).
- Секция «Фильмы» не меняется.

## Подходы

| Что           | Варианты                               | Выбор                                                                                |
| ------------- | -------------------------------------- | ------------------------------------------------------------------------------------ |
| Anki          | тот же чекбокс; отдельная кнопка       | чекбокс: один способ сохранения в одном списке                                       |
| Кружок        | SVG; CSS conic-gradient                | SVG: одинаков в Chrome и Firefox, подложка не зависит от превью                      |
| Плеер         | ссылка на сайт Flib; окно внутри popup | сайт: владелец просит «наш плеер»; окно YouTube по щелчку на карточке остаётся       |
| Кнопка плеера | видна всегда; только при наведении     | всегда: появление при наведении сдвигает список, а на сенсорном экране наведения нет |

## Что решено

0. Чекбокс есть у всех видео из примеров: у обычных, «с учётом знаний» и фильмов он уже есть, добавляется «Понятным».
1. **Чекбокс у «Понятных»**: тот же `_createSelectCheckbox('inline')`, ничего не отмечено заранее, ключ из
   `_youTubeKeySeq`. Участвует в счётчике «В Anki · N видео», в `getSelectedGatewayMedia` и `clearSelection`.
   Переключение «С учётом моих знаний» отметки у «Понятных» не снимает.
2. **Что сохраняется**: элемент `youtube` с `ref`, `startMs` = начало первой реплики и её текстом. Реплики нет →
   `startMs` 0 и название ролика; нет и названия → «YouTube». Порядок: как на экране, «Понятные» выше.
3. **Кружок** 34 px в левом верхнем углу превью вместо текстовых плашек у обеих кнопок: белая подложка, дуга по
   доле, число без «%». Без доли кружка нет.
4. **Цвет** по округлённому числу: ≥ 80 зелёный, 60–79 жёлтый, < 60 красный. Границы — решение исполнителя. Цвет не
   единственный признак: число видно всегда.
5. **Подсказка и `aria-label`**: «понятно N% фрагмента» (С учётом моих знаний), «понятно N% ролика» (Понятные).
   Подсказки у кнопок: первая — «Фрагменты со словом, отсортированные по знакомым вам словам», вторая без изменений.
6. **«Открыть в плеере»** на каждой карточке YouTube (обычной, «с учётом знаний», «Понятные»): ссылка в новой вкладке
   на `https://flib.club/player?v=<id>`, `rel="noopener noreferrer"`. Адрес строит
   `buildFlibPlayerUrl` в `gateway-examples-util.js` из `FLIB_SITE_URL` (литерал домена остаётся только в
   `flib-host.js`) с проверкой `isValidYouTubeRef`.
   Без `rp` страница не маршрутная, поэтому событий маршрута она не создаёт.

7. **Плеер YouTube в карточке Anki** (решение владельца 2026-11-24: только Yomitan Card Type). Вместо одной строки поле
   `flib_media` несёт на каждый ролик встроенный плеер `youtube-nocookie.com/embed/<id>?start=<s>[&end=<s>]` без
   автозапуска, `loading="lazy"`, `referrerpolicy="strict-origin-when-cross-origin"`, `allowfullscreen`, и под ним
   прежнюю ссылку с репликой (без сети и там, где плеер не работает, остаётся она). `end` — конец реплики с запасом
   2 с; у «Понятных» `end` нет. Нужен новый `endMs` в `GatewaySelectedYouTube` и `FlibMediaFieldYouTube`: пишет панель,
   читает `buildYouTubeItem`.
   - Шаблоны Anki и их ревизии не меняются: плеер живёт внутри поля. ReverseDeck и Phrases не трогаем.
   - `mergeFlibMediaFieldHtml`: `iframe` и `style` сейчас признаки опасной разметки. Наш плеер узнаётся
     по разобранному дереву: адрес, перечень атрибутов и перечень допустимых объявлений стиля, включая вид, в который их
     приводит редактор; любой другой `iframe` остаётся опасным. Повтор ролика — по id и секунде из адреса плеера, если его
     конец не раньше нового.
   - Если в поле уже есть список `ul.flib-yt`, новый оборачивается в `div.flib-yt-more`: CSS шаблона шире 900 px ставит
     все списки в одну клетку, и плеер закрыл бы прежнее.
   - Размер задаёт `style` самого iframe (ширина 100%, не больше 480px, 16:9): шаблон и его CSS не меняются.
   - Прежняя ссылка без плеера не считается повтором нового элемента с плеером: пересохранение того же ролика добавит
     плеер, старые байты поля не меняются.
   - Старые карточки с одной ссылкой не переписываются.

### Проверено для п. 7 (2026-11-24)

Отдельный Anki 26.05 (QtWebEngine 6.11, Linux, виртуальный экран, пустой профиль), карточка с `start=563&end=570`:
плеер получает referrer `http://127.0.0.1:<порт>/`, ошибки 153 нет, по щелчку играет 854 px, `currentTime` идёт
563→570 и останавливается на 570 — и на youtube.com, и на youtube-nocookie.com. Не проверены: звук (он был отключён),
Windows, macOS, AnkiDroid, AnkiMobile, AnkiWeb, окно редактора.

## Начало с нужной секунды

Владелец 2026-11-24: «Да: открывать с &t=». Ссылка несёт `&t=<целые секунды>` — начало реплики, вниз до секунды; нуля и
негодного времени в адресе нет. Плеер сайта читает `v`, `rp`, `rc`, `back`, `route_step`; `t` пока не читает, ролик
начнётся с нуля. Читателя делает сессия flib.club отдельной задачей, выпуск 0.6.1 её не ждёт.

## Граничные случаи

1. Нет реплик, нет названия — п. 2.
2. Один ролик отмечен и в «Понятных», и в списке с тем же временем — в поле одна ссылка (без повторов по адресу).
3. `coverage` / `known_share` отсутствует, NaN, меньше 0 или больше 1 — нет кружка или зажим 0..100.
4. 79,6% показывается как 80 и красится как 80; 100% — три цифры помещаются.
5. Щелчок и Enter/Space на ссылке и чекбоксе не открывают окно YouTube.
6. Второе нажатие «Понятные» и новые карточки сверху не снимают отметки прежних.
7. Сохранение прошло — отметки сняты у всех сохранённых; отмеченное во время сохранения остаётся.
8. Панель закрыта во время сохранения — прежнее поведение отмены. Superseded 2026-11-25: сохранение завершается.
9. Негодный `ref` — ссылки на плеер нет.
10. Поле со старой ссылкой, поле с нашим плеером, поле с чужим `iframe` при обновлении карточки — без потери байтов
    и без повторов нашего ролика.
11. Реплика без `endMs`, `endMs` ≤ `startMs` — плеер без `end`.
12. Плотный вид (превью 7.2em), popup ≥ 720 px, светлая и тёмная темы, Firefox.

## Принято и уточнено после проверки плана

- Кружок в плотном виде 26 px, метка времени там только с началом: на превью 96×54 px вместе не помещаются.
- Два и больше клипов фильмов вместе с плеерами на экране шире 900 px: второй клип уходит ниже плееров (сетка шаблона
  Anki). Принято, шаблон не меняем.
- Нижняя строка панели считает отметки: один момент, отмеченный в двух списках, даёт «2 видео» и одну ссылку. Остаётся
  элемент «Понятных», без `end`.
- Реплика с пустым текстом: секунда берётся из неё, текст — название ролика.
- Firefox: владелец 2026-11-24 согласился добавить категорию `websiteActivity`.
- Потребитель выбора, не названный выше: `_clearSavedGatewaySelection` в `display-anki.js`; строка 457 — запись.

## Решения владельца 2026-11-25

- Нажатое сохранение всегда завершается, одинаково для YouTube и фильмов («Смысл один: сохранить»): новый поиск и
  закрытие панели его не отменяют, ни при добавлении, ни при обновлении карточки. Отмечаемое берётся при нажатии.
  Неудача после нового поиска показывается с тем словом, которое не сохранилось. Граничный случай 8 отменён.
- Видео сохраняются и из окна фразы (Alt+Shift+A): при добавлении — в новую заметку, у существующей фразы
  обновляется только `flib_media`.
- Обновление меняет только заметку своей колоды и своего типа из формата карточки («Мы работаем только со своей
  колодой»). Нет такой — сообщение, ничего не меняется. Параллельное изменение одной карточки не исправляем.
