Ревьюер: независимый агент, режим «только отчёт» (код и страница не менялись).

Метод: элементы и команды извлечены из JS-данных страницы (`N`, `C`, `EDGES`, `FLOWS`, `IMPORT`, `GLOSS`) в headless Chromium (playwright + `/usr/bin/chromium`); выборочно сверены с кодом репозитория. Скриншоты лежат только в scratchpad.

## 0. Вердикт по главному утверждению

Проверяемое утверждение: «у каждого элемента каждого уровня (C1, C2, C3a, C3b, C4) есть ВСЕ части: что/ответственность, как запускается со всеми параметрами, артефакты с точными местами и процессами, как запустить и проверить».

**Утверждение НЕ выполняется.** Из 50 элементов ни на одном уровне нет полного покрытия:

| Часть                                   | Есть у                                                                                                                         | Нет у                   |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ | ----------------------- |
| 1. Что это / за что отвечает (`simple`) | 50 / 50                                                                                                                        | 0                       |
| 2. Как запускается (`start`)            | 23 / 50                                                                                                                        | **27**                  |
| 3. Артефакты с местом (`artifacts`)     | 11 / 50 (из них у `cs` — «—»)                                                                                                  | **39**                  |
| 4. В каких процессах участвует          | связи (`EDGES`) у 50 / 50; сценарии (`FLOWS`) только у 19 элементов уровня 3; в панели элемента сценарии не показываются вовсе | частично у всех         |
| 5. Как запустить и проверить (`cmds`)   | 36 / 50                                                                                                                        | **14**                  |
| C4 (уровень кода) как отдельный уровень | нет: только таблица «файл:строка → что там» в карточках 20 компонентов уровня 3                                                | не уровень с элементами |

Шаблон панели (`panel()`, строки 1245–1264) молча опускает пустой раздел: `${start ? … : ""}`, `${arts ? … : ""}`, `${cmds.length ? … : ""}`. Поэтому читатель не может отличить «не применимо» от «забыли»: у элемента просто нет заголовка «Как запускается». Это главный структурный дефект, из него вытекает бо́льшая часть HIGH.

Обозначения в матрице: **P** — есть и достаточно; **T** — тонко (есть только в прозе/«Фактах», без места на диске, без параметров или без проверки); **M** — нет, хотя у элемента это реально есть; **n/a** — по сути неприменимо (человек, внешний сайт), но страница этого **не говорит** (по строгому требованию это тоже дефект, MED); «нз» — проверка есть, но ни разу не запускалась при подготовке.

## 2. HIGH (читатель не может выполнить задачу / нет обязательной части)
